# Вибіркові ТНТУ — розумний підбір

Браузерне розширення для студентів ТНТУ, яке спрощує вибір вибіркових дисциплін на [dl.tntu.edu.ua](https://dl.tntu.edu.ua/mods/elective_courses/all.php).

На сайті кредити, форма контролю чи рекомендований рік видно лише в силабусі кожного курсу. Розширення збирає ці дані для всіх курсів одразу, враховує ваші обов'язкові дисципліни і допомагає набрати потрібну кількість кредитів.

> Неофіційний інструмент, не пов'язаний з ТНТУ. Перед поданням заяви перевіряйте дані на сайті й у деканаті.

## Можливості

- **Каталог з фільтрами.** Ті самі фільтри, що й на сайті: мова, підрозділ, спеціальність, ступінь, семестр. Додатково можна фільтрувати за кредитами, формою контролю (екзамен, залік чи диф. залік), рекомендованим роком навчання й наявністю курсової. Є вигляд списком і таблицею, сортування, порівняння до 4 курсів.
- **Дані вашого акаунта.** Розширення читає обов'язкові дисципліни, вкладки «Обрані мною» та «Мене цікавлять», рекомендації випускової кафедри й індивідуальний навчальний план. Курси, які у вас обов'язкові або вже вивчені, ховаються з каталогу, а схожі за назвою позначаються.
- **План і варіанти.** Курси розкладаються по семестрах з лімітом кредитів. Можна мати кілька варіантів плану («План A», «План B»…) і порівнювати їх.
- **Підбір комбінацій.** Розширення знаходить набори курсів, що дають рівно потрібну суму кредитів.
- **ШІ-підбір через Gemini.** Працює з вашим власним API-ключем: ви описуєте побажання, і ШІ пропонує набори курсів на осінь або весну. Пропонує лише курси з вашого списку, якщо він є.
- **Звіт по семестрах.** Обов'язкові й обрані курси, кількість екзаменів, заліків і курсових, оцінки й середній бал. Звіт можна скопіювати в Excel або надрукувати.
- **Оформлення.** Тема «ТНТУ» в стилі сайту, а також класична, темна й системна. Інтерфейс адаптивний, працює і на телефоні.

## Встановлення

1. Завантажте або склонуйте репозиторій.
2. Відкрийте `brave://extensions` (або `chrome://extensions`) і ввімкніть **«Режим розробника»**.
3. Натисніть **«Завантажити розпаковане»** і виберіть папку `extension/`.
4. Зайдіть на dl.tntu.edu.ua → **Вибіркові дисципліни**. Внизу праворуч з'явиться кнопка **🔎 Розумний підбір**.

При першому запуску розширення попросить прочитати [умови користування](TERMS.md) й погодитися з ними. Лише після цього воно читає дані вашого акаунта.

Після оновлення коду натисніть ↻ біля розширення в `brave://extensions` і оновіть сторінку сайту.

### ШІ-підбір (необов'язково)

1. Створіть безкоштовний ключ на [aistudio.google.com/apikey](https://aistudio.google.com/apikey).
2. Вставте його на вкладці **✨ ШІ-підбір**.

Ключ зберігається лише у вашому браузері, у сховищі розширення. Що саме надсилається в Google, описано в [TERMS.md](TERMS.md).

### Без розширення

Відкрийте `index.html` у браузері. Каталог, фільтри, план і звіт працюватимуть, але обов'язкові дисципліни доведеться вводити вручну.

## Конфіденційність

- Логін і пароль розширення не бачить: воно працює у вашій уже відкритій сесії на сайті.
- План, налаштування й прочитані дані зберігаються лише у вашому браузері.
- Розширення нічого не змінює у вашому акаунті й не подає заяв від вашого імені.

Детальніше — в [TERMS.md](TERMS.md).

## Для розробників

### Структура

```
extension/            готове розширення (його завантажують у браузер)
  manifest.json       маніфест MV3; при кожній зміні піднімайте "version"
  app.js              ЗГЕНЕРОВАНИЙ інтерфейс — не редагуйте, див. src/app/
  content/            скрипти, що читають сторінки сайту в сесії студента
  background.js       сервіс-воркер: запити до Gemini API
  css/                стилі, підключаються через css/index.css у порядку каскаду
  courses.json        дані каталогу для розширення (генерує scrape.py)
  data.js             ті самі дані для index.html
src/app/              частини інтерфейсу; збираються в extension/app.js
build.py              збирач extension/app.js
scrape.py             збір каталогу і силабусів з dl.tntu.edu.ua
index.html            окрема сторінка без розширення
```

### Команди

```bash
python3 build.py           # зібрати extension/app.js з src/app/*.js
python3 build.py --check   # перевірити, що app.js зібраний з актуальних частин
python3 scrape.py          # оновити каталог: extension/courses.json і data.js
```

`scrape.py` кешує силабуси й відповіді фільтрів у `cache/`. Щоб завантажити все наново, видаліть цю папку.

### Поширення

```bash
python3 package.py           # зібрати app.js і створити dist/vybirkovi-tntu-<версія>.zip
python3 package.py --icons   # те саме + перегенерувати іконки (потрібен Pillow)
```

Архів містить лише файли, потрібні розширенню (без `data.js` для `index.html`). Його можна:

- **надіслати іншим.** Вони розпаковують архів, відкривають `chrome://extensions` → «Режим розробника» → «Завантажити розпаковане» і вибирають розпаковану папку;
- **завантажити в магазин.** Підходять [Chrome Web Store](https://chrome.google.com/webstore/devconsole) (разовий внесок $5) або [Microsoft Edge Add-ons](https://partner.microsoft.com/dashboard/microsoftedge) (безкоштовно). З магазину розширення встановлюється в один клік і оновлюється автоматично; Chrome Web Store працює і в Brave, Opera та Vivaldi.

### Домовленості

- Документація коду ведеться англійською у форматі JSDoc, а текст інтерфейсу — українською.
- Файли тримаємо невеликими: нову функціональність виносимо в окрему частину `src/app/NN-*.js`, окремий CSS чи окремий скрипт у `content/`.
- При кожній зміні розширення піднімайте `version` у `extension/manifest.json`.

### English summary

Unofficial MV3 browser extension that helps TNTU students pick elective courses on dl.tntu.edu.ua. It aggregates syllabus data (credits, assessment type, recommended year), reads the student's mandatory courses, curriculum and selections from their own logged-in session, hides already-taken courses, finds course combinations that hit an exact credit target, offers optional Gemini-based suggestions with the user's own API key, and produces a per-semester report. UI code lives in `src/app/` and is assembled into `extension/app.js` by `build.py`; the catalog is refreshed with `scrape.py`. Code is documented with English JSDoc.
